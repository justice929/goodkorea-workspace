## 🚀 Vision & Philosophy
우리는 단순한 앱 개발을 넘어, 사용자의 소중한 시간을 지키고 비즈니스의 성공을 가속화하는 '지능형 자동화'를 추구합니다. 모든 프로젝트는 아래의 **3대 개발 원칙**을 엄격히 준수합니다.

1. **One-Click Automation**: 모든 복잡한 과정을 클릭 한 번으로 끝냅니다.
2. **Zero-Learning**: IT 소외 계층도 설명서 없이 즉시 사용할 수 있는 직관적 UX를 지향합니다.
3. **Fail-Safe**: 기술적 오류 상황에서도 사용자가 당황하지 않는 완벽한 방어 시나리오를 구축합니다.

### 🍱 먹장먹살 (MokjangMoksai) — v1.0 MVP
**"식당 성공을 돕는 AI 리뷰 관리 솔루션"**
- **Core Value**: 사장님의 리뷰 답글 스트레스 제로(0). 
- **Features**: 
  - AI 기반 진정성 있는 장문 답변 자동 생성 (Gemini 1.5 Flash 엔진)
  - 크롬 익스텐션을 활용한 전 플랫폼(배민, 네이버 등) 원클릭 스캔 및 자동 입력
  - 플랫폼별 통합 평판 관리 및 홍보 문구 자동화
