## 📱 대본 1: [브이로그/공감형] "오늘도 장난으로 달린 별점 1점에..."
**타겟**: 감정 노동에 지친 사장님 (멘탈 케어 강조)
**예상 길이**: 25초
**BGM**: 잔잔하고 약간 슬픈 감성의 로파이(Lo-Fi) 비트 (뒤에서 반전됨)

| 초(Sec) | 화면 연출 (Visual) | 내레이션 (Audio) / 자막 |
| :--- | :--- | :--- |
| 0~3초 | 피곤한 얼굴로 주방에 주저앉아 폰(배달앱 리뷰창)을 보며 한숨 쉬는 사장님 뒷모습. (화면 흑백 처리) | (자막 쾅!) 오늘도 '공깃밥 양 적다'는 억지 별점 1점에 멘탈 나가셨나요? |
| 3~8초 | 핸드폰 화면 클로즈업. 리뷰 답글 창에 글을 썼다 지웠다 반복하는 손가락. | 화는 나는데... 뭐라고 답글 달아야 할지 막막해서 썼다 지웠다 반복하고 계시죠? |
| 8~15초 | 화면 밝아짐(컬러 전환). 사장님이 '먹장먹살' 버튼을 딸깍 누름. 화면에 AI가 쓴 깔끔한 답글이 촤르륵 타이핑됨. | 사장님, 이제 감정 소모 하지 마세요. [먹장먹살] 스티키 바 버튼 하나면 끝납니다. |
| 15~20초 | 앞치마를 벗으며 홀가분하게 퇴근하는 사장님. | 진상 고객 방어부터 단골 관리까지, AI가 알아서 사장님 톤으로 답글을 써줍니다. |
| 20~25초 | 먹장먹살 로고 화면 + 하단 프로필 링크 클릭 그래픽 | 사장님 멘탈 지키고 퇴근 시간 30분 앞당기는 숨은 기능! 지금 프로필 링크에서 확인하세요. |

## 📱 대본 2: [화면녹화/실무형] "배달앱에서 사장님들만 모르는 숨은 기능"
**타겟**: 효율과 속도를 중시하는 사장님 (시간 단축 강조)
**예상 길이**: 20초
**BGM**: 빠르고 경쾌한 비트 (트렌디 팝)

| 초(Sec) | 화면 연출 (Visual) | 내레이션 (Audio) / 자막 |
| :--- | :--- | :--- |
| 0~3초 | 배달의민족 리뷰 관리 창. 마우스 커서가 바쁘게 움직임. | (자막 강조) 배달앱에서 사장님들만 모르는 숨은 기능, 3초 만에 보여드립니다! |
| 3~10초 | 리뷰 텍스트 복사 -> 먹장먹살 팝업창(배민 모드) 클릭 -> '답변 생성' 클릭 (빠른 배속) | 악성 리뷰 복사하고, 버튼 하나 딸깍 누르면? 고객 톤앤매너에 딱 맞춘 완벽한 AI 답글 완성! |
| 10~15초 | 요기요, 쿠팡이츠 모드 탭을 넘나들며 답글이 변하는 모습 시연 | 배민은 친근하게, 쿠팡은 고급스럽게 알아서 맞춰줍니다. |
| 15~20초 | 시계가 돌아가는 그래픽 (퇴근 시간 단축) + 화살표 애니메이션 | 매일 밤 리뷰 달던 30분, 이제 3분으로 줄이세요! 프로필 링크 클릭! |

## 📱 대본 3: [경고/공포소구형] "리뷰 테러 한 번에 주문량 반토막"
**타겟**: 매출 하락에 예민한 사장님 (매출 방어 강조)
**예상 길이**: 20초
**BGM**: 긴장감 넘치는 사이렌 또는 시계 초침 소리 째깍째깍

| 초(Sec) | 화면 연출 (Visual) | 내레이션 (Audio) / 자막 |
| :--- | :--- | :--- |
| 0~3초 | 텅 빈 홀 사진 위로, 우하향하는 붉은색 매출 그래프 합성. 화면 상단 경고 띠 🚨 | (경고음) 리뷰 테러 한 번에 주문량 확 줄어드는 동네 장사, |
| 3~8초 | 진상 고객의 리뷰("맛없어요", "별로네요") 캡처본이 화면에 툭툭 던져짐 | 계속 이렇게 당하고만 계실 겁니까? 억울해도 감정적으로 대응하면 사장님만 손해입니다. |
| 8~14초 | 먹장먹살 AI가 진상 리뷰에 논리적이고 정중하게 방어하는 텍스트가 타이핑됨 | 진상 고객의 부당한 요구? 감정 소모 없이 논리적이고 깔끔하게 AI로 방어하세요. |
| 14~20초 | 먹장먹살 로고 + 타이머 마감 임박 효과 | 지금 세팅 안 하면 경쟁 가게에 밀립니다. 당장 프로필 링크를 클릭해 방어 시스템을 구축하세요! |
